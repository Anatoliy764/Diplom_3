## Diplom_3
### Обзор
Проект **Diplom_3** предназначен для тестирования веб-приложения с использованием современных инструментов автоматизации. Основное внимание уделено UI-тестированию с помощью Selenide, API-тестированию с Rest-Assured, а также генерации отчетов через Allure.

---

### Сборка и запуск тестов
#### **Шаг 1. Установка предварительных условий**
- Убедитесь, что у вас установлены:
    - Java 11 или выше.
    - Maven 3.x или выше.

#### **Шаг 2. Клонирование репозитория**
Склонируйте проект на ваш локальный компьютер:
``` bash
git clone https://github.com/Anatoliy764/Diplom_3.git -b develop3
```
#### **Шаг 3. Запуск тестов**
Для запуска тестов выполните команду:
``` bash
mvn clean test -fn -X -e
```

Для запуска тестов в браузере яндекс пропишите переменную среды BROWSER=yandex и повторите запуск тестов:
``` bash
set BROWSER=yandex
```


#### **Шаг 4. Просмотр Allure отчета**
После выполнения тестов создайте отчет Allure с помощью команды:
``` bash
allure serve target/surefire-reports/
```
